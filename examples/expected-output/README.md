# Expected output examples

These YAML files are golden examples for review and demo rehearsal. They are intentionally outside `modules/`, so Steep sync and live Cursor generation still start from an empty output folder.

- `finance/` answers the Finance questions in `business-context.md`: MRR/ARR by plan, TPV trend, and revenue by country.
- `operations/` answers the Operations questions: transaction success rate, failed transaction concentration, and KYB approval time.

Use them as a baseline, not as a replacement for live generation.
